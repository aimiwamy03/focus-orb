# Focus Orb — Cut 001 (v1, localhost)
Date: 2026-10-07 | Owner: Amy Wang | Status: building

Decision needed: none for v1. Google OAuth and the macOS menu bar app are out of this cut.

## Goal
A browser tab with a dithered, glowing particle sphere (style reference: attached image, white stipple dots on near-black #161616). The orb is dense and bright during a focus block and slowly scatters as the next meeting approaches, so the time is felt without checking a calendar.

## In (this cut)
- Next.js (App Router, TypeScript) app, runs with `npm install && npm run dev` on localhost:3000. Deployable to Vercel unchanged.
- Full-screen canvas particle sphere (2D canvas or WebGL), roughly 6–12k points, soft breathing motion, 60fps on a laptop.
- "Scatter" value 0..1 drives the look: 0 = tight bright dense sphere; 1 = sparse, dim, particles drifting outward like the reference's lower-right edge.
- Calendar via a private iCal (ICS) URL (Google Calendar "Secret address in iCal format"), pasted in a settings panel, stored in localStorage only. Fetched through a Next.js API route (avoids CORS); refresh every 5 min. Handles recurring events and all-day events (ignore all-day).
- Scatter mapping: >=60 min to next meeting -> 0; ramps to 1 at meeting start (ease-in, configurable window 15/30/60/90 min). During a meeting: orb dims to a calm low-glow state. No meetings left today: steady full orb.
- Manual focus mode with no calendar: start a 25/50/90-min focus block; scatter ramps over the last part of the block.
- Minimal text overlay, hidden by default, shown on hover: next meeting title + "in 23 min". Keyboard: `f` fullscreen, `s` settings, `space` start/stop manual block.
- Tab title + favicon reflect state (e.g. "● 23m" counting down) so it works as a pinned tab.
- Demo mode (`?demo=1`) that cycles scatter 0 -> 1 over 60s, for screenshots and testing without a calendar.
