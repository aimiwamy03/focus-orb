# CUT-007: Bigger, readable type

Date: 2026-10-21. Base: `main` (PR #9 merged, then reverted in #10).

Amy's live Ask screen at ~686px wide reads too small and hurts her eyes.

## Acceptance

- **AC1** Raise the type scale on every state with fluid `clamp()` sizing. Baseline at 1280x800: question/heading about 28-32px, task input about 24px, status line about 18px, recent-task suggestions and chips about 17-18px, Start a real button about 18px with comfortable padding. Hints and keycaps at least 14px. Corner chrome at least 15px. Same proportional scale on focusing, meeting, completed, break, settings, and the `?` panel.
- **AC2** Nothing overlaps or clips at 1280x640, 1440x900, 1024x768, or 686x386. The orb shrinks to make room. Keep the existing short-viewport rules.
- **AC3** Contrast stays WCAG AA. Keep the palette test green. Recent-task suggestions must be clearly readable, not dim.
- **AC4** The mini orb / PiP label scales too and stays centered.
- **AC5** The Ask input starts empty with placeholder `Focus`. Recent tasks (up to 3, deduped, most recent first) show as tappable suggestions and never duplicate what is already typed. Starting with an empty input (orb click or Enter) uses the last task, else the most recent suggestion, else `Focus`.
- **AC6** Settings calendar rows tag imported calendars (`id` ends with `@import.calendar.google.com`) as `(imported)` and holiday calendars (`#holiday@group.v.calendar.google.com`) as `(holidays)`, styled like `(primary)`. Selection is unchanged.
- **AC7** Game-menu keyboard on every button row. Highlight is a filled pill, never a focus ring. Idle Ask shows a quiet keycap hint near the chips (`← → to choose, Enter to start`). Other states stay quiet.

### AC7 keyboard

- **Input vs chips.** While the Ask field is focused, Left/Right move the caret. Up, Down, or Tab moves to the duration chips (and blurs the field). Shift+Tab from the first chip, or Up from the chip row, returns to the input. Once the field is not focused, Left/Right and Tab change the selected chip (wrap, skip disabled). Enter starts with that duration.
- **End early.** Keep going is highlighted by default. Left/Right and Tab move between Keep going and End. Enter confirms the highlighted button. Esc is Keep going.
- **Completed.** Same pattern on Take a break / Another round. Another round is highlighted by default.
- **Meeting soon.** Join / Skip when a join link exists. Join is highlighted by default. Enter joins. Esc is Skip, which dismisses the prompt so Ask can start a session.
- **AC8** A translucent left agenda (about 280px, no white card) shows remaining events for today, then Tomorrow, then the next day if height allows. Past events are hidden. Each row has a calendar-colored bar, a truncated title, and a hyphenated time (`7-8pm`), or `Now` if it is in progress. The next event is brighter. Status line: `Free until 7:00, then <Event title>.` Shown in Ask, break, completed, and meeting soon. During focusing it hides with the chrome and fades in on mouse move. Hidden under ~900px width, when it would overlap the orb, or when Settings `Show agenda` is off (default on). Empty today reads `Nothing else today.`

### AC8 agenda

- **Layout.** Absolute left column, vertically centered. The orb stays centered; the panel never pushes it. If the orb disk would collide with the panel, the agenda hides.
- **Time copy.** Hyphen only, never an en dash. Drop `:00`. Keep am/pm on the shared end, or on both sides when the range crosses noon.
