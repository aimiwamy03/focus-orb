# Focus Orb Screenshots

This directory contains screenshots for the README and documentation.

## Screenshots

### 1. focus-state.png
**Focused State with Calendar**
- Shows the main interface with the orb in a focused/cohesive state
- Left sidebar displays the calendar with upcoming meetings (Design sync, Standup, Review)
- Message: "Free until 1:30, then Design sync."
- Focus duration options visible (25m, 50m, 90m, Until next meeting)
- Start button and Sample day link at bottom
- Perfect for showing the main use case: scheduling focused work time

### 2. sample-day.png
**Sample Day View**
- Displays the sample day demo with mock calendar events
- Orb is in a moderately focused state
- Shows Thursday, October 22 with three meetings scheduled
- Good for demonstrating the app without requiring actual calendar connection
- Shows the clean, minimalist interface design

### 3. meeting-scattered.png
**Scattered State During Meeting**
- Shows the orb in a dispersed/scattered state during an active meeting
- Darker particles spread out more widely
- Message: "In Standup. Free at 3:00."
- Timeline visualization at bottom showing meeting schedule
- Demonstrates the visual metaphor: scattered particles = scattered attention during meetings
- Perfect contrast to the focused state

## Usage

These screenshots demonstrate the core concept of Focus Orb:
- Visual representation of focus time (cohesive orb) vs. meeting time (scattered particles)
- Integration with calendar to show upcoming commitments
- Simple, beautiful interface for managing focus sessions
